# hoje-output

Claude Code 응답을 한국어로 간결하게 정규화하는 output style입니다.

## 무엇이 달라지나

- 서론과 맺음말 없이 결론부터 시작합니다.
- 최종 답변은 불릿 1~5개, 전체 300자 내외로 제한됩니다. 불릿 하나는 한 문장을 기본으로 하며, 필요한 경우에만 두 문장까지 씁니다.
- 이미 `Edit`나 `Write`로 파일에 쓴 코드를 답변에 다시 붙이지 않고 `경로:줄번호`로만 가리킵니다.
- 클래스명·메서드명·변수명은 사용자가 그것으로 무언가를 찾거나 실행하거나 판단해야 할 때만 등장합니다.
- 요청하지 않은 대안, 트레이드오프, 후속 작업 제안이 붙지 않습니다.
- 이모지와 `좋은 질문입니다` 같은 정보 없는 상투구를 쓰지 않습니다.

## 분량 제한이 풀리는 경우

사용자에게 선택·확인 또는 권한·계획 승인을 요청하는 답변에는 300자 제한을 적용하지 않습니다. 선택·확인 질문은 `AskUserQuestion` 도구로 묻고, 선택지가 다섯 개 이상이면 본문에 나열합니다. 권한 요청과 계획 승인은 Claude Code의 기본 승인 흐름을 따르며, 어떤 경우에도 판단에 필요한 사실을 분량 때문에 잘라내지 않습니다.

## 유지되는 것

`keep-coding-instructions: true`로 선언되어 있어 Claude Code의 기본 코딩 지시가 시스템 프롬프트에 그대로 남습니다. 보안 취약점 회피, 주석 작성 규칙, 불필요한 추상화 금지 같은 지시가 사라지지 않습니다.

## 언어

한국어 응답 전용 규칙과 `~했습니다` 완료 보고 어미 규칙이 들어 있습니다. 한국어로 작업하는 사용자를 위한 스타일입니다.

## 사용법

플러그인을 설치하고 활성화하면 `force-for-plugin: true` 설정에 따라 사용자의 기존 `outputStyle` 설정을 재정의하고 자동으로 적용됩니다. 따로 선택할 필요가 없으며, 같은 설정을 사용하는 플러그인이 여러 개면 먼저 로드된 스타일이 적용됩니다.
